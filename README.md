# Customer Shopping Behavior Analysis

## 📌 Project Overview

The goal of this project is to simulate a corporate-grade, end-to-end data analytics workflow, translating raw data into strategic business intelligence by:

- ✅ **Data Preparation, Modeling & EDA (Python):** Clean and transform the raw dataset for analysis.
- ✅ **Data Analysis (SQL):** Run queries to extract insights on customer segments, loyalty, and purchase drivers.
- ✅ **Visualization & Insights (Power BI):** Build an interactive dashboard that highlights key patterns and trends for data-driven decisions.
- ✅ **Report:** Summarize key findings and business recommendations.

## 📊 Key Findings

- Total revenue **$233,081** from **3,900** customers; average purchase **$59.76**.
- **Clothing** brings the most revenue (45%).
- **Subscribers don't spend more** ($59.49 vs $59.87).
- **80%** of customers are loyal (more than 10 previous purchases).
